🚀 Pesa Tracker – Personal Expense Management System

Pesa Tracker is a Java-based desktop application designed to help users efficiently manage and analyze their personal finances. It enables users to record daily expenses, categorize spending, and gain insights through interactive reports and visual charts.

💡 Key Features
📌 Add, edit, and delete expenses
🗂️ Categorize transactions (e.g., Food, Transport, Utilities)
📊 Visualize spending using pie, bar, and line charts (JFreeChart)
📅 Generate monthly and custom financial reports
🔍 Filter expenses by date and category
💾 Persistent storage using PostgreSQL
🏗️ Tech Stack
Language: Java
Database: PostgreSQL
Visualization: JFreeChart

🎯 Goal

To provide a simple yet powerful tool for individuals to track expenses, understand spending habits, and make smarter financial decisions.
